# Color Hunt - 색깔 찾기 스피드 게임

카메라 앞에 **요구한 색의 물건을** 보여주면 통과하는 OpenCV 기반 스피드 게임입니다.
Jetson(USB 카메라)과 일반 노트북 웹캠 모두에서 같은 코드로 실행 가능합니다.

<br>

---

## 파일 구조

* `Project1-Color_Hunt.py`: 게임 전체 코드 (색 검출, 문제 출제, 화면 표시, 게임 루프, 카메라 열기)
* `README.md`: 이 문서

별도의 이미지, 모델, 설정 파일은 필요 없습니다.

| `color_hunt.py` 안의 구성 | 역할 |
|---|---|
| `detect()` | 프레임에서 R/G/B 물건의 위치를 찾는 핵심 함수 |
| `put_text()`, `draw_boxes()`, `draw_hud()` | 글자, 박스, 상단 안내(HUD) 그리기 |
| `COMBOS`, `new_round()` | R/G/B 7가지 조합 중 문제를 뽑고 제한 시간 계산 |
| `open_camera()` | Jetson CSI → USB → 노트북 웹캠 순으로 카메라 열기 |
| `main()` | 게임 상태(`title` → `play` → `over`)와 키 입력 처리 |

## 실행 방식

### 준비
```bash
pip install opencv-python numpy
```

### 실행
```bash
python Project1-Color_Hunt.py
```
- Jetson(USB)에서는 VAL2를 사용하고, 노트북(웹캠)에서는 DirectShow를 사용하여 두 환경에서 모두 실행 가능하게 하였습니다.

### 조작 키

| 키 | 동작 |
|---|---|
| `SPACE` | 시작 / 게임오버 후 재시작 |
| `D` | 빨강/초록/파랑 마스크 미리보기 on/off (화면 오른쪽 아래) |
| `E` | CLAHE 조명 보정 on/off |
| `Q` | 종료 |

### 게임 방법
1. 상단에 `FIND:` 뒤로 찾을 색이 나옵니다. (예: RED + GREEN)
2. 제한 시간 안에 **그 색의 물건만** 카메라에 보여줍니다.
3. 정답 색상이 0.5초 동안 유지되면 통과하고 다음 문제로 넘어갑니다.
4. 문제에 없는 색이 보이면 통과되지 않고, 화면에 `REMOVE: BLUE`처럼 경고가 뜹니다.
5. 시간이 다 되면 게임오버와 함께 최종 점수가 표시됩니다.

| 항목 | 규칙 |
|---|---|
| 문제 | R, G, B로 만들 수 있는 7가지 조합(R, G, B, RG, RB, GB, RGB) 중 랜덤, 같은 조합 연속 출제 X |
| 1라운드 제한 시간 | 색 1개 8초 / 2개 10초 / 3개 12초 |
| 시간 감소 | 라운드마다 8%씩 감소, 최소 30%에서 멈춤 (10라운드부터 바닥) |
| 점수 | 색 개수 × 10 + 남은 초(int) |

### 색이 잘 안 잡힐 때
`D` 키로 마스크를 보면서, 정답 물건만 하얗게 잡히도록 `COLORS`의 HSV 숫자를 조정합니다.
손이나 옷이 같은 색으로 잡히면 해당 색의 S(채도) 최솟값을 올립니다. 조명이 안 맞으면 `E`로 CLAHE를 켭니다.

## 창의성 및 확장성

### 아이디어 설명
카메라 앞에 주어진 색깔 물건을 빨리 보여줘야 하는 스피드 게임입니다.
처음에는 정해진 색으로 허공에 도형을 그리는 게임을 기획했지만, 도형 인식이 불안정하고 코드가 복잡해져서 **색 검출 하나에 집중한 게임**으로 변경했습니다.
규칙이 단순한 대신, 게임으로서 재미 요소를 위해 아래 장치를 넣었습니다.
- 정답 색**만** 보여야 통과 (물건 3개를 계속 들고 있는 꼼수 방지)
- 라운드가 지날수록 시간이 줄어들어 난이도 상승
- 통과 안 된 이유를 화면에 바로 피드백 (`REMOVE: ...`, 회색 `X` 박스)

### 구현한 내용
- **색 검출 파이프라인**: 프레임 → 좌우반전 → 가우시안 블러 → (CLAHE) → HSV → `inRange` → Opening/Closing → `findContours` → 가장 큰 덩어리의 bounding box
- **일치 판정**: 검출된 색의 집합과 문제의 색 집합을 `set`으로 비교(`set(found) == set(need)`)해서, 모자라거나 남으면 통과하지 않습니다.
- **유지 시간 판정**: 정답이 처음 맞은 시각(`ok_since`)을 기록하고, 하나라도 틀어지면 초기화합니다. 순간적인 깜빡임으로 통과되는 것을 막습니다.
- **7가지 조합 출제**: `itertools.combinations`로 조합 7개를 만들고, 직전 문제를 뺀 나머지에서 `random.choice`로 뽑습니다.
- **난이도 곡선**: `제한 시간 = 기준 시간 × max(0.3, 1 − 0.08 × (라운드 − 1))`
- **빨강의 두 구간 처리**: 빨강은 HSV의 H가 0 근처라서 두 범위를 OR로 합칩니다.
- **환경 자동 선택**: 운영체제를 보고 Jetson이면 GStreamer(CSI) → USB, 노트북이면 기본 웹캠을 엽니다.

### 사용한 수업 기술

| 기술 | 사용한 곳 |
|---|---|
| 이미지 조정 | `cv2.flip` (거울 모드), `cv2.resize` (마스크 미리보기 축소) |
| 색공간 변환 | BGR → LAB → BGR → HSV, 마스크 GRAY → BGR |
| Image Enhancement | CLAHE (LAB의 L 채널에만 적용. `E` 키로 on/off) |
| 필터링 | 7×7 가우시안 블러 |
| Color Segmentation | `cv2.inRange` + 비트 OR(빨강) |
| Morphology | Opening → Closing |
| Contour Detection | `findContours`, `contourArea`, `boundingRect` |
| 객체 추적 | 프레임마다 색으로 재검출하고, 정답 유지 시간(`ok_since`)으로 시간 축 연속성을 판단 |
| 결과 표현 | 박스/라벨 오버레이, 색 칩, 줄어드는 시간 바, 유지 진행 바, 경고 문구 |

### 확장성
- **신체 인식 연동**: "물건을 손에 들고 있어야 통과" 같은 규칙 추가. 손 또는 피부색과 물건 박스가 겹치는지 판정하면 신체와 객체의 관계를 게임 규칙에 적용할 수 있습니다.
- **색 늘리기**: `COLORS`에 노랑 등을 추가하면 `COMBOS`가 자동으로 늘어납니다. (색이 n개면 조합은 2ⁿ−1개)
- **2인 대결**: 같은 문제를 먼저 맞히는 사람이 이기는 모드로 확장할 수 있습니다.
- **기록 저장**: 최고 점수 저장, 난이도(`SHRINK_PER_ROUND`) 선택 메뉴.

## 기타 참고 사항

### 작업 중 경험한 문제점
1. **프로젝트 방향 변경**: 처음 기획한 "허공에 도형 그리기" 게임은 도형 판별 로직이 길고 설명하기 어려워서, 코드를 완벽히 이해하고 발표·질의응답을 할 수 있도록 색 찾기 게임으로 바꿨습니다.
2. **반칙 방지**: 초기 규칙은 "요구한 색이 보이면 통과"여서 세 가지 색 물건을 다 들고 있으면 어떤 문제든 통과됐습니다. "문제의 색만 검출될 때 통과"로 규칙을 바꿔 해결했습니다.
3. **난이도 조절**: 시간을 고정하면 난이도가 낮아서 라운드마다 시간이 줄어들도록 했습니다.

### 한계
- 색만으로 물건을 구분하기 때문에, 배경이나 옷, 피부가 같은 색으로 잡히면 오검출될 수 있습니다. HSV 범위와 조명에 민감합니다.
- HSV 범위는 일반적인 시작값이라 카메라와 조명에 따라 직접 조정이 필요합니다.
- 신체 인식 등의 심화 객체 추적은 구현하지 못했습니다.
